# QRiosity – Exhibition Management System

## Description

QRiosity is a web application designed to manage an exhibition. It provides tools for organizing exhibition content and managing different types of users.

## Main Features

- **Account Management:** Manage user accounts and profiles.
- **Artwork Management:** Organize and display artworks.
- **Exhibition Management:** Manage exhibition information.
- **News Management:** Publish and display news.
- **Ticket Management:** Manage exhibition tickets.

## Technologies Used

- PHP
- CodeIgniter 4
- MySQL
- SQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Database

The project includes a relational database designed with MySQL Workbench.

The database documentation includes:
- Relational database schema (`schema.sql`)
- MySQL Workbench model (`schema_relationnel.mwb`)
