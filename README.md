# QRiosity – Système de gestion d'expositions

## Présentation du projet

QRiosity est une application web destinée à faciliter la gestion d'expositions à l'aide de QR codes.

Ce projet individuel a été réalisé dans le cadre de ma Licence 3 Informatique. Il porte sur le développement d'une application web et la conception d'une base de données relationnelle.

## Fonctionnalités principales

- **Gestion des visiteurs** : gestion des informations relatives aux visiteurs.
- **Gestion des actualités** : publication et consultation des actualités.
- **Gestion des galeries** : organisation et présentation des contenus de l'exposition.
- **Livre d'or** : espace permettant aux visiteurs de laisser des messages.
- **Gestion des utilisateurs** : prise en charge de différents types d'utilisateurs.

## Technologies utilisées

**Développement web**
- PHP
- CodeIgniter 4
- HTML5
- CSS3
- Bootstrap

**Base de données**
- MySQL
- SQL

**Outils**
- MySQL Workbench
- phpMyAdmin
- Git et GitHub

## Conception de la base de données

La conception de la base de données a été réalisée individuellement. Elle comprend :

- La réalisation du modèle conceptuel de données (MCD).
- L'élaboration du schéma relationnel.
- La définition des tables, des attributs et des contraintes d'intégrité.
- L'implémentation de la base de données avec SQL.
- La création et l'insertion des données nécessaires au fonctionnement de l'application.

## Travail réalisé

Le projet a été développé à partir d'une base de code et de certaines ressources fournies par l'enseignante.

Mon travail a notamment porté sur :

- La création de nouvelles fonctionnalités et de composants de l'application.
- La modification et l'adaptation de contrôleurs, modèles et vues existants.
- L'écriture et l'exécution de requêtes SQL pour interroger et manipuler les données.
- La conception et l'implémentation de la base de données.

## Structure du projet

- `application/ci/` : application web développée avec CodeIgniter 4.
- `Base de données/` : fichiers de conception et scripts SQL.

## Objectifs pédagogiques

Ce projet m'a permis de mettre en pratique mes compétences en développement web, programmation PHP, conception de bases de données relationnelles et manipulation de données avec SQL.
